# Music Production & Magenta Studio Workspace (Ableton Live 12 Standard + RodeCaster Duo)

This workspace bridges **Magenta Studio v2.0** and an **AI Co-Producer CLI** directly into **Ableton Live 12 Standard** without requiring Max for Live or Ableton Suite.

## Quick Start

### 1. Enable `AbletonOSC` in Ableton Live 12 Standard (One-Time Setup)
`AbletonOSC` has been installed into your Ableton User Library (`Documents\Ableton\User Library\Remote Scripts\AbletonOSC`).
1. Open **Ableton Live 12 Standard** (restart it if it was already open).
2. Open **Settings** (`Ctrl + ,`) -> **Link, Tempo & MIDI**.
3. Under **Control Surface**, choose **`AbletonOSC`** in any empty row (leave Input and Output set to `None`).
   - You'll see `"AbletonOSC: Listening for OSC on port 11000"` in Ableton's bottom status bar.

### 2. Configure RodeCaster Duo Audio Inputs in Ableton
1. In **Settings** (`Ctrl + ,`) -> **Audio**:
   - Set **Driver Type** to **ASIO** and **Audio Device** to **RODECaster Duo ASIO** (or WASAPI / RodeCaster Duo Main Multitrack).
2. Add this workspace folder (`C:\Users\Chris Barnes\Projects\Music`) to Ableton's Browser sidebar by clicking **Add Folder...** under **Places**.

### 3. Launch Magenta Studio v2.0
- Double-click [`Launch-Magenta-Studio.bat`](./Launch-Magenta-Studio.bat) or open **`http://localhost:3333`** in your browser.
- All 5 Magenta Studio tools (**Continue**, **Drumify**, **Generate**, **Groove**, **Interpolate**) will show all MIDI tracks from your open Ableton Live 12 session, plus **`📁 Local MIDI Clips Folder`** (`./MIDI Clips`).
- Every clip generated by Magenta Studio is inserted directly into your Ableton Session View slots **and** automatically saved as a `.mid` file in [`MIDI Clips/`](./MIDI%20Clips).

### 4. One-Command Quick Recording Session Setup
Once Ableton Live 12 has `AbletonOSC` enabled, run:
```powershell
node studio-cli.js setup-session 110
```
This automatically sets up:
- **Track 1 (`Magenta Drums`)**: Seeded with `BoomBap Drums` (Slot 1) and `House Groove` (Slot 2) mapped to Magenta's 9-drum GM pitches (`36, 38, 42, 46, 45, 48, 50, 49, 51`).
- **Track 2 (`Magenta Melody`)**: Seeded with two monophonic A-minor melodies (`SynthArp` & `SoulHook`) ready for **Continue**, **Interpolate**, or **Drumify**.
- **Track 3 (`Chords & Keys`)**: Seeded with a 4-bar Neo-Soul (`Am9 -> Em9 -> Fmaj9 -> Dm9/E7#9`) progression.
- **Track 4 (`RodeCaster Mic/Vox`)**: Audio track for vocals/mic.
- **Track 5 (`RodeCaster Inst/Gtr`)**: Audio track for guitar/bass/hardware synth.
